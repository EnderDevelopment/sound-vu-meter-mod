# Sound VU Meter Mod

A visual HUD that responds to in-game sounds in Minecraft.

## Features

- Visual HUD that responds to in-game sounds
- Adjustable VU meter height based on sound volume

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or later
- Fabric API 0.79.0 or later

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/sound-vu-meter-mod/releases).
2. Place the downloaded JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

Once installed, the VU meter will automatically appear on the right side of your screen. It will rise and fall in response to sounds in the game.

## Configuration

The mod does not have a configuration file. The VU meter height and width are hardcoded in the mod.
